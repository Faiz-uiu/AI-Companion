# AI 伴侣

基于 Streamlit 和 DeepSeek API 构建的智能伴侣聊天应用，支持人格设定、流式回复、会话历史管理和深色简约聊天界面。

## 项目功能

- 支持用户自定义 AI 伴侣昵称和性格
- 支持 DeepSeek API 流式回复
- 支持聊天记录保存与历史会话切换
- 使用黑灰色调设计简约聊天界面
- 通过环境变量读取 API Key，避免密钥写入代码

## 技术栈

- Python
- Streamlit
- OpenAI SDK
- DeepSeek API
